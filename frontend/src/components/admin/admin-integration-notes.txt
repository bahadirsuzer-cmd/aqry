Admin email'i frontend koda hardcode ETME.

==================================================
SECURITY
==================================================

Frontend:
- service-role key içermez.
- auth session ile RPC çağırır.

Database:
- her admin RPC önce is_aqryo_admin() kontrol eder.
- admin_users client'tan insert/update/delete edilemez.

Creator:
- /admin route'u açabilir ama admin değilse veri alamaz ve erişim ekranı görür.
- route gizlemek güvenlik değildir; asıl güvenlik DB RPC'dedir.

==================================================
MVP YETKİLER
==================================================

Admin görebilir:
- creator sayısı/listesi
- Experience sayısı/listesi
- paid orders
- brüt TRY
- reportlar
- payoutlar

Admin değiştirebilir:
- sadece report workflow status
  new
  reviewing
  resolved
  dismissed

==================================================
BİLEREK EKLENMEYEN TEHLİKELİ AKSİYONLAR
==================================================

Admin MVP şu an YAPAMAZ:
- creator silmek
- auth user silmek
- order status elle paid yapmak
- refund basmak
- payout paid yapmak
- finance balance değiştirmek
- Experience silmek
- report üzerinden otomatik ban
- creator parasını elle değiştirmek

Bu işlemler daha sonra ayrı:
- validation
- authorization
- idempotency
- audit log
ile güvenli RPC olarak yapılmalı.

==================================================
