==================================================
EXPERIENCE STATUS MODEL
==================================================

status:
draft
published
paused
archived
...

paused_by:
null
creator
moderation

creator pause:
status = paused
paused_by = creator
pause_reason = null

moderation pause:
status = paused
paused_by = moderation
pause_reason = internal moderation reason
moderated_at
moderated_by

==================================================
CREATOR RULE
==================================================

Creator:
published -> paused
paused_by=creator

Creator reopen:
paused + paused_by=creator -> published

Creator CANNOT:
paused + paused_by=moderation -> published

Bu kontrol UI'da değil DB RPC'de yapılır.

==================================================
ADMIN RELEASE
==================================================

Admin moderation kilidini kaldırınca Experience doğrudan publish edilmez.

moderation pause
↓
admin release
↓
status = paused
paused_by = creator
↓
creator isterse tekrar yayınlar

Bu daha güvenli ve creator'a son kontrolü verir.
