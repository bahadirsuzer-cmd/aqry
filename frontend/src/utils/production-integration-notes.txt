==================================================
SOCIAL CRAWLERS
==================================================

Important:
Many messaging/social crawlers do NOT execute full React JavaScript.

Therefore client-side document meta updates may NOT create reliable:
- WhatsApp previews
- X cards
- Telegram previews

If tests fail, production solution should be:
- server rendered metadata
or
- edge-generated share page
or
- prerender

Do not assume React document.title is enough for social cards.
